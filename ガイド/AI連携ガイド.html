試作の機能です。Mojicast v1.1 からの機能で、AIアプリ側の画面や名前は今後変わることがあります。 このガイドの画面は 2026年10月時点のものです。

1. できること

AIアプリに「字幕を左下にまとめて」「この言葉を派手にして」と話しかけるだけで、AIが Mojicast の設定を変えてくれます。 変えた内容は OBS の字幕にすぐ反映されます。

  • 字幕のデザイン（フォント・文字の大きさ・色・縁取り・光彩・登場のしかた）
  • 字幕枠の位置・大きさ・背景・行数
  • 言葉ごとのエフェクト（虹色・キラキラ・紙吹雪など）
  • 認識辞書・伏せ字・英訳の固定
  • 配信ログを読んで、名前などの誤認識を探す
  • 話さずに字幕を1行出して、見た目を確かめる
  • 直前の変更を取り消す（「さっきの方がよかった、戻して」）

AIに「左下にまとめて」「文字を大きく、黒い縁取りを太めに」「『いらっしゃい』を派手に」と頼んだあとの字幕。

この仕組みを MCP（AIアプリに道具を足すための共通の仕組み）といいます。 Mojicast の MCP は、あなたのパソコンの中で動く Mojicast につなぐので、パソコンにインストールするAIアプリから使います。 ブラウザで開く ChatGPT や Gemini からは使えません。

AIアプリ登録のしかたメモ
Claude デスクトップ設定ファイルに書く無料プランでも使えます。いちばんおすすめ
ChatGPT（Codex）画面から入力ChatGPT デスクトップアプリの Work モード（Codex）で使います
Gemini（Antigravity）設定ファイルに書くGoogle の Antigravity アプリで使います

2. 準備（どのAIでも共通）

① Mojicast を起動しておく

AIは起動中の Mojicast に話しかけます。使うときは Mojicast を起動しておいてください（認識は止まっていても大丈夫です）。

② uv を入れる（最初の1回だけ）

Mojicast の MCP は uv という小さなツールで動きます。スタートメニューで「PowerShell」を開き、次の1行を貼り付けて Enter を押してください。

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

終わると C:\Users\（あなたのユーザー名）\.local\bin\uv.exe ができます。このあと使うので場所を覚えておいてください。

③ mojicast_mcp.py の場所を確かめる

Mojicast のフォルダの中の mcp フォルダに mojicast_mcp.py があります。

入れ方ふつうの場所
インストーラ版C:\Users\（ユーザー名）\AppData\Local\Programs\Mojicast\mcp\mojicast_mcp.py
Zip版Zip を展開したフォルダの Mojicast\mcp\mojicast_mcp.py

エクスプローラーで mojicast_mcp.py を右クリック →「パスのコピー」で、場所をそのままコピーできます。

3. Claude デスクトップで使う

① 設定ファイルを開く

Claude デスクトップの設定（Ctrl+,）→ 左の一覧の下の方の「開発者」→「設定を編集」を押します。 claude_desktop_config.json というファイルが入ったフォルダが開くので、メモ帳で開いてください。

② mojicast を書き足す

中身が空（または {} だけ）なら、下をそのまま貼り付けて、2か所の「ユーザー名」と mojicast_mcp.py の場所を自分のものに書き換えます。

{
  "mcpServers": {
    "mojicast": {
      "command": "C:\\Users\\ユーザー名\\.local\\bin\\uv.exe",
      "args": ["run", "--script",
               "C:\\Users\\ユーザー名\\AppData\\Local\\Programs\\Mojicast\\mcp\\mojicast_mcp.py"]
    }
  }
}
  • パスの \ は 2つ重ねて \\ と書きます（このファイルの決まりです）。
  • すでに "mcpServers" がある場合は、その中に "mojicast": { … } の部分だけを足します（前の項目との間に , を入れます）。
  • uv は uv.exe の場所をフルパスで書いてください。Claude デスクトップは uv だけだと見つけられないことがあります。

③ Claude を完全に終了して、起動し直す

ウィンドウを閉じるだけでは終わりません。タスクバー右下（通知領域）の Claude アイコンを右クリックして「終了」してから、もう一度起動します。 設定 →「開発者」に mojicast「実行中」と出ていれば成功です。

④ 話しかける

新しいチャットで、ふつうに頼むだけです。AIが Mojicast の道具（ツール）を順に使って、字幕を変えてくれます。

「mojicast連携を使用しました」を開くと、AIがどの道具を使ったかが見られます。

4. ChatGPT（Codex）で使う

ChatGPT のデスクトップアプリ（Codex が入ったもの）で使います。ここは設定ファイルを書かずに、画面から入力できます。

① 設定 → プラグイン → MCP を開く

設定（Ctrl+,）→ 左の「連携」にある「プラグイン」→ 上のタブの「MCP」を開きます。

② 「追加」→「MCP サーバーを追加」

③ 入力して保存する

項目入れるもの
名前mojicast
タイプSTDIO
起動用コマンドuv（動かないときは uv.exe のフルパス）
引数「＋引数を追加」で3つに分けて、run／--script／mojicast_mcp.py の場所

環境変数・作業ディレクトリは空のままで大丈夫です。最後に「保存する」を押します。

画面は入力例です。3つめの引数は、自分の mojicast_mcp.py の場所にしてください。

④ Work モードで話しかける

新しいチャットを開き、上の切り替えを Work にして頼みます。プロジェクトは「プロジェクトを使わない」で大丈夫です。

「OBS Studio の使用を許可しますか？」と聞かれたら
Codex が仕上がりを確かめようとして、パソコンの画面操作（Computer Use）で OBS を触ろうとすることがあります。 字幕の変更には必要ないので、「拒否」で大丈夫です。仕上がりは自分の OBS の画面で確かめてください。

5. Gemini（Antigravity）で使う

Google の Antigravity アプリ（エージェントの画面）で使います。設定ファイルに書き足す方法です。

① 設定ファイルの場所をコピーする

左の「Customizations」→ 右上の「Installed」を開き、いちばん下の MCP Servers の横にある コピーのアイコン（Copy Config File Path）を押します。設定ファイルの場所がコピーされます。

② 設定ファイルに mojicast を書き足す

エクスプローラーのアドレス欄にコピーした場所を貼り付けて開き、メモ帳で編集します（ふつうは C:\Users\（ユーザー名）\.gemini\config\mcp_config.json）。 書き方は Claude と同じです。

{
  "mcpServers": {
    "mojicast": {
      "command": "uv",
      "args": ["run", "--script",
               "C:\\Users\\ユーザー名\\AppData\\Local\\Programs\\Mojicast\\mcp\\mojicast_mcp.py"]
    }
  }
}

すでに別の MCP が書いてある場合は、"mcpServers" の中に "mojicast": { … } だけを足します。

③ Antigravity を起動し直す

Antigravity を閉じて開き直し、Customizations → Installed の MCP Servers に mojicast（緑の点）・18 tools enabled と出ていれば成功です。

④ 話しかける

「New Conversation」で頼みます。「Worked for …」を開くと、使った道具（update_design · mojicast など）が見られます。

6. 頼み方の例

やりたいこと頼み方の例
位置を変える「字幕がアバターに被ってる。画面の左下にまとめて」
見た目を変える「フォントを丸くて可愛い感じに。縁取りはピンクで」
「ゲーム画面でも読みやすいように、文字を大きく、黒い縁取りを太めに」
言葉を目立たせる「『いらっしゃい』に派手なエフェクトをつけて」
誤認識を直す「昨日の配信ログを見て、私の名前を間違えているところがあれば辞書に登録して」
確かめる「試しに長めの字幕を2〜3行出してみて」
戻す「さっきの方がよかった。戻して」

ざっくり頼んで、見ながら「もう少し大きく」「やっぱり白に」と少しずつ直していくのがおすすめです。

OBS の MCP（AI から OBS を操作する仕組み）も一緒に入れておくと、AI が OBS の画面を見てアバターの位置を確かめてから字幕を動かす、といった使い方もできます。

7. 気をつけること・困ったとき

気をつけること

  • 変更は配信画面にすぐ出ます。配信中に試すときは気をつけてください。
  • AIに頼んでいる間は、Mojicast の「字幕デザイン」「単語」の編集窓を閉じてください。開いたまま保存すると、その窓の内容で上書きされます。
  • 認識辞書・伏せ字・英訳の固定は、認識を止めて始め直すまで効きません（AIは配信を止めないように、自分では再起動しません）。言葉のエフェクトはすぐ効きます。
  • 「戻して」で取り消せるのは、AIアプリを起動している間の変更だけです。
  • 同梱のデザインを残したいときは「今のデザインを複製してから変えて」と頼んでください。

困ったとき

こんなとき確かめること
mojicast が「実行中」にならない・赤い点になる ・uv を入れたか（準備②）
・mojicast_mcp.py の場所が合っているか、\\ と2つ重ねて書いたか
・uv を uv.exe のフルパスに変えてみる
・書き足したあと、AIアプリを起動し直したか
AIが「Mojicast に接続できない」と言うMojicast が起動しているか。ポート番号を 8765 から変えている場合は、環境変数 MOJICAST_PORT にその番号を設定してください
初めて使うときに時間がかかる1回目だけ、uv が必要な部品をダウンロードします（1分ほど）
指定したフォントが OBS で出ないそのフォントを「すべてのユーザーにインストール」し直してください。自分のユーザーだけに入れたフォントは OBS のブラウザソースで使えないことがあります
