AI連携は使いたい人だけの追加機能です。設定しなくても、Mojicastの音声認識・字幕表示はそのまま使えます。このガイドはWindows版の手順です。2026年11月5日改訂。AIアプリの画面名・利用条件は版やアカウントによって異なります。

0. 全体の流れ

やることは5つだけです。所要時間は初回で10〜15分ほど。2回目以降は何もしなくても使えます。

  1. 補助ツール「uv」を入れる（初回だけ・コマンドを2回貼り付けるだけ）
  2. Mojicastで接続キーを発行する（ボタンを押してコピー）
  3. このページで接続設定をつくる（コピーしたものを貼り付けると、設定が自動でできあがります）
  4. できた設定をAIアプリに貼り付けて、AIアプリを開き直す
  5. AIに「つながった？」と聞いて確かめる

専門用語は覚えなくて大丈夫です。黒い枠の中の文字は、右上の「コピー」ボタンでコピーできます。
3〜4の作業は、ファイルを編集できるAIにまるごとおまかせすることもできます。
配信中・画面共有中は作業しないでください。途中で表示される接続キーが映ってしまいます。

1. AI連携でできること

「字幕をもう少し大きく」「この言葉にキラキラを付けて」と頼むと、AIがMojicastの設定を操作します。これをつなぐ仕組みが MCP です。仕組みを覚える必要はありません。

  • 字幕の色・フォント・位置や、言葉ごとの演出を調整する
  • 認識辞書や固定訳の登録を手伝ってもらう
  • 許可した場合だけ、保存済みログから誤認識の候補を探す

AIに見た目の調整を頼んだ字幕の例。配信中も変更はすぐ反映されるので、最初は配信していない状態で試しましょう。

使えるAIアプリ

ブラウザで開くチャット画面（claude.ai・chatgpt.com・gemini.google.com）からはつながりません。PCにインストールして使うアプリが必要です。次のうちどれか1つあれば大丈夫です。

普段使っているものこのガイドで使うアプリ
ClaudeClaude デスクトップ（Windows用のClaudeアプリ）
ChatGPTCodex など、ローカルMCPを登録できるOpenAIのデスクトップ環境
GeminiGoogle Antigravity（普段のGeminiチャットとは別のアプリです）

アプリの設定に「MCPサーバー」を追加する場所が見当たらない場合は、アプリを最新版に更新するか、各公式手順を確認してください。MojicastをインターネットへURL公開する必要はありません。

2. トークンは「Mojicast専用の接続キー」

Mojicastが自動で作る長い文字列です。このキーを登録したAIアプリにだけ、Mojicastの操作を許可するために使います。パスワードを考えたり、文字列の意味を理解したりする必要はありません。

よくある疑問答え
AIの「何トークン消費」と同じ？別物です。ここでは接続キーのこと。文字数や利用料金の単位ではありません
ChatGPTやGeminiのAPIキーが必要？いりません。使うのはMojicastが発行したキーだけです。AIアプリ自体の利用条件・料金は別です
どこへ貼る？基本は、このページの接続設定メーカーで作った設定に入れて、AIアプリの設定へ登録します。設定をAIにおまかせするときだけ、チャットで渡してもかまいません。OBSのURL欄には貼りません
毎回入力する？一度登録すれば不要です。再発行したときだけ登録し直します

キーは発行したときだけ表示されます。分からなくなったら再発行できます。他人に共有したり、スクリーンショット・配信画面へ映したりしないでください。

3. 準備①：補助ツール「uv」を入れる

uvは、Mojicastに同梱しているAI連携用のプログラムを動かすための無料の補助ツールです。一度入れれば、次回からはこの章は不要です。

① PowerShell（黒や青の文字入力の画面）を開く

キーボードの Windowsキー を押し、そのまま powershell と入力して Enter を押します。「管理者として実行」は不要です。

② 次の1行をコピーして貼り付け、Enterを押す

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

PowerShellの画面では 右クリック（または Ctrl+V）で貼り付けられます。uv公式サイトのインストーラーを実行するコマンドです（uv公式のインストール手順）。文字が流れて止まり、次の入力待ちに戻ったら完了です。

③ PowerShellを閉じて、もう一度開く

ここが大事です。開き直さないと、入れたばかりのuvが見つかりません。①と同じ方法で開いてください。

④ uvの場所をコピーする

開き直したPowerShellに次の1行を貼り付けてEnterを押します。uvの場所が表示され、同時にコピーもされます。

$p = (Get-Command uv).Source; $p; Set-Clipboard $p

C:\Users\（ユーザー名）\.local\bin\uv.exe のような表示が出たら成功です。このまま5章の②欄に貼り付けられます（先に4章へ進んでも、もう一度このコマンドを実行すれば大丈夫です）。

赤い文字で「'uv' は…認識されません」と出たら、③の開き直しをもう一度。それでもだめなら②からやり直してください。

4. 準備②：Mojicastで接続キーを発行する

  1. Mojicastを起動します（認識は止めたままで大丈夫です）。
  2. 「アプリ設定」を開き、左の一覧から 「AI連携」 を選びます。
  3. 「トークンを発行・再発行」 を押します。
  4. 下に長い文字列が表示され、選択された状態になります。そのまま Ctrl+C でコピーします。

「AI連携」で、接続キーとログ共有を別々に設定できます。「AIに保存済みログの読み取りを許可する」はOFFのままで大丈夫です。

「MCP接続：有効」は、キーが発行されているという意味です。AIアプリとつながったかどうかは、最後の7章で確かめます。
キーは画面を閉じると二度と表示されません。コピーし忘れたら、もう一度「トークンを発行・再発行」を押せば新しいキーが出ます。

5. 接続設定をつくる（このページで自動作成）

ここまでにコピーしたものを貼り付けると、AIアプリに登録する設定が自動でできあがります。このページはインターネットに何も送信しません。入力した内容は保存されず、ページを閉じると消えます。

① 使うAIアプリ
③ Mojicastの種類
空欄のままでも設定は作れます。その場合は、できた設定の「ここをMojicastで発行したトークンに置き換える」を自分で書き換えてください。
他のMCPなど、すでにある設定を消さずに合体させるために使います。

AIに設定をまるごとおまかせする


手順が面倒なら、PCのファイルを編集できるAI（Claude Code・Codex・Antigravityなど）に、接続キーごと渡して設定してもらってもかまいません。普段のチャット画面（ブラウザ版など）では設定ファイルを書き換えられないので、この方法は使えません。


MojicastのMCP接続設定をしてください。
Mojicastの mcp フォルダにある mojicast_mcp.py を、uv run --script で起動する設定です。
接続キー（MOJICAST_TOKEN）は「ここにMojicastで発行したキー」です。
既存のMCP設定は消さずに追加してください。
終わったら、接続の再起動方法を教えてください。


「ここにMojicastで発行したキー」を4章でコピーしたキーに置き換えて送ります。設定が終わったら、AIアプリを開き直して接続確認を行います。


気をつけるのは「漏らさない」ことだけです。キーを渡した会話を配信や画面共有に映したり、会話の共有リンクを人に送ったりしないでください。なお、会話の内容はAIの会社のサービスに保存されます。

とはいえ、キーが漏れても大きな被害にはなりにくい作りです。MojicastはこのPCの中からの接続しか受け付けないため、他の人がネット越しにキーを使うことはできません。キーでできるのもデザイン・辞書などの調整だけで、伏せ字の削除・ログ読み取りの許可・録音の開始はできません。気になったら、いつでも「トークンを発行・再発行」で古いキーを無効にできます（AIアプリ側も新しいキーに置き換えてください）。



キーは渡さず、設定の下準備だけ手伝ってもらう場合

キーをAIに見せたくない場合は、仮の値で設定を作ってもらい、キーだけ自分で書き込みます。次の文をそのまま頼んでください。


MojicastのMCP接続設定を手伝ってください。
mojicast_mcp.pyの場所は「ここにファイルの場所」です。
既存のMCP設定を消さずに追加してください。
MOJICAST_TOKENの値は私が接続設定に入力するので、仮の値にしてください。
トークンをチャットへ貼るよう求めたり、設定から読み出して表示したりしないでください。
キーを入力する場所と、接続の再起動方法を教えてください。


AIが用意した設定の仮の値を、自分で接続キーに置き換えます。その後、AIアプリを開き直して接続確認を行います。



7. つながったか確かめる


Mojicastを起動したまま、AIアプリで新しい会話を開いて、次の文をそのまま送ります。ここには接続キーを書きません。


Mojicastの接続状態を確認してください。
mojicast_statusを使い、今のデザイン名とレイアウト名を教えてください。
まだ設定は変更せず、ログも読まないでください。


AIが mojicast_status を実行して、今のデザイン名とレイアウト名を答えれば接続成功です。AIアプリが「このツールの使用を許可しますか？」と聞いてきたら、mojicastのツールであることを確かめて許可してください。


「接続しました」という文章だけで、デザイン名などが出てこない場合は、つながっていない可能性があります。9章を確認してください。


次に、小さな変更を試す


今のデザインを複製してから、字幕の文字を少し大きくしてください。
ログは読まず、見た目だけ調整してください。


OBSやMojicastのプレビューで確認します。試しの字幕を出したいときは、認識を止めた状態で「試しに1行表示して」と頼みます。Mojicastの字幕を調整するだけなら、OBS側の設定変更は不要です。


  • 「『いらっしゃい』にキラキラを付けて」
  • 「文字は白、縁取りは黒で読みやすくして」
  • 「さっきの変更を戻して」（AIアプリを開き直すまでの変更だけ戻せます）


AIに調整を頼んでいる間は、Mojicastのデザインや単語の編集画面を閉じておいてください。開いたまま保存すると、古い内容で上書きされます。辞書・伏せ字・固定訳の変更は、認識を停止して再開すると反映されます。



8. ログを読ませたいときだけ許可する


  1. 「画面とログ」で字幕ログが保存されていることを確認します。
  2. 共有する内容を確認し、「AI連携 → AIに保存済みログの読み取りを許可する」をONにします。
  3. 「直近1回のログから名前の誤認識候補を出して。辞書への登録は確認してから」と頼みます。
  4. 使い終わったらOFFに戻せます。次の取得から拒否されます。


音声認識はPC内のままですが、AIが取得したログや辞書などの情報は、AIアプリの設定に応じて外部サービスへ送られる場合があります。OFFに戻しても、すでに渡った内容は取り消せません。接続キーを登録しただけでログ読み取りがONになることはありません。



9. 困ったとき・接続をやめるとき


症状確認すること


PowerShellで「'uv' は…認識されません」PowerShellを閉じて開き直してから再実行します。だめなら3章②のインストールからやり直します


5章で「JSONとして読めません」と出る⑤欄の中身が途中で切れていないか確認します。メモ帳で Ctrl+A → Ctrl+C をやり直して貼り直してください


AIアプリにmojicastが出てこないメモ帳で上書き保存したか、AIアプリを完全に終了して開き直したかを確認します。ファイル名が …json.txt になっていないかも確認してください


mojicastが「起動できない」「失敗」と表示される5章の②③の場所が正しいか確認します。エクスプローラーでその場所を開き、uv.exe と mojicast_mcp.py が本当にあるか見てください


認証が必要／401／MOJICAST_TOKENが必要接続キーが入っていないか、「ここを…置き換える」の文章のままです。5章の④にキーを入れて作り直し、AIアプリを開き直します


再発行したら動かなくなった古いキーは無効です。5章で新しいキーを入れて設定を作り直し、AIアプリ側を置き換えて開き直します


キーを見失った・人に見せてしまったMojicastで再発行し、AIアプリ側も更新します。使わないなら「MCP接続を無効化」を押します


接続できないMojicastが起動しているか確認します。ポートを変えた場合は、5章の「ポートを変えている場合だけ」に番号を入れて作り直します。OBS用のURLはAIアプリには入れません


ログの読み取りが拒否される／403キーとは別にログ共有の許可が必要です（8章）。他の操作で403なら、AI連携では許可されていない操作です


ログ許可をONにしても「ログがない」読み取り許可はログ保存を始める設定ではありません。「画面とログ」の保存設定と、保存済みログの有無を確認します


初回だけ時間がかかるuvが必要な部品をダウンロードするため、ネット接続が必要です。2回目からは速くなります


連携を使わなくなったら


「AI連携 → MCP接続を無効化」で、そのキーによる以後のアクセスを止められます。AIアプリ側のmojicast接続も無効化・削除できます。Mojicastの通常の字幕機能は引き続き使えます。


AI連携ではログ許可の変更・トークン管理・録音開始はできません。既存の伏せ字も削除できません（AI自身が追加した語の取り消しは可能）。Mojicast本体のAPIは同じPCからの接続に限定していますが、同じOSユーザー権限でファイルを直接操作するプログラムを隔離する仕組みではありません。
