# Mojicast MCP サーバ（試作）

## 接続用トークン（この版から必須）

Mojicast の「設定 → AI連携 → AIアプリと接続する」でトークンを発行し、AIアプリのMCP接続設定に環境変数 `MOJICAST_TOKEN` として登録してください。接続設定を変更したらMCPを再起動します。既存の接続設定にも追加が必要です。パスワードの設定は不要です。

```json
"env": {"MOJICAST_TOKEN": "設定画面で発行したトークン"}
```

`env` は `command` / `args` と同じ階層に追加します。Codex の TOML 設定なら対象サーバーの `env = { MOJICAST_TOKEN = "設定画面で発行したトークン" }` に相当します。

トークンは発行時だけ表示されます。紛失時は再発行してください。再発行・無効化は以前のトークンを直ちに無効化し、アプリ再起動後も維持されます。トークンをチャットや共有リポジトリへ貼らないでください。

専用トークンでできるのはデザイン・レイアウト・辞書・演出の操作、試し表示、および別途許可されたログの取得です。ログ許可の変更、認証情報の管理、録音開始、ファイルのインポート／エクスポートはできません。設定画面の認証はアプリ起動時に自動で行われます。OBSの表示URLは変更不要です。

この認証はローカルHTTP APIの操作を制限します。同じOSユーザー権限で設定ファイルやプロセスを直接操作できるプログラムを隔離するものではありません。OBS用の現在の字幕・表示情報は従来どおりローカルから参照できます。


Claude Code などの AI から、Mojicast の字幕デザインとレイアウトを言葉で調整するための MCP サーバです。
起動中の Mojicast の HTTP API を中継するだけなので、Mojicast 本体には何も追加しません。

## 役割分担

| やりたいこと | 使う MCP |
|---|---|
| 字幕レイヤー全体（ブラウザソース）の位置・大きさ | OBS MCP |
| 仕上がりの確認（スクリーンショット） | OBS MCP |
| レイヤーの中での字幕枠の位置・背景・行数 | Mojicast MCP（`update_layout`） |
| フォント・色・縁取り・光彩・登場アニメ | Mojicast MCP（`update_design`） |
| 話さずに字幕を1行出す | Mojicast MCP（`show_sample_caption`） |
| 単語のエフェクト（色・動き・パーティクル） | Mojicast MCP（`set_word_effect`） |
| 認識辞書・伏せ字・固定訳への登録 | Mojicast MCP（`add_words` / `remove_words`） |
| 配信ログから誤認識を探す | Mojicast MCP（`read_recent_logs`） |

## 登録

[uv](https://docs.astral.sh/uv/) が必要です。依存（`mcp<2`）は uv が自動で用意します。

```
claude mcp add mojicast -s user -- uv run --script <Mojicast のフォルダ>\mcp\mojicast_mcp.py
```

`<Mojicast のフォルダ>` は Mojicast.exe があるフォルダです（開発版では `tools\mcp\mojicast_mcp.py`）。

Mojicast のポートを 8765 から変えている場合は、`-e MOJICAST_PORT=ポート番号` を付けてください。
登録後は Claude Code を開き直すと使えます。

## 頼み方の例

- 「字幕をアバターに被らないように、画面の下の左寄りに帯で出して」
- 「フォントをもう少し丸くて可愛い感じに。縁取りはピンクで」
- 「さっきの方がよかった、戻して」
- 「『癒色えも』に派手なエフェクトをつけて」
- 「昨日の配信ログを見て、名前の誤認識があれば登録候補を出して」

## 注意

- 変更は配信画面に**すぐ反映**されます。配信中に試すときは気をつけてください。
- `undo` で戻せるのは、この MCP サーバが起動している間の変更だけです。
- 調整中は Mojicast の「字幕デザイン」編集窓を閉じてください。開いたまま保存すると、その窓の内容で上書きされます。
- 伏せ字は AI から足せますが、外せません。外すときは Mojicast の「単語」画面を使ってください（ログなどに紛れた指示で伏せ字が外れ、配信に NG ワードが出る事故を防ぐため）。
- 認識中は試し表示（`show_sample_caption`）を出しません。AI が指示した文がそのまま配信画面に出るのを防ぐためです。
- ログ読み取りは初期値OFFです。利用する場合は Mojicast の「設定 → AI連携」で「AIに保存済みログの読み取りを許可する」をONにしてください。ログ保存とは独立した設定で、OFFに戻すと次の取得から拒否します。MCPには許可を変更するツールはありません。
- `read_recent_logs` で取得した内容は、接続したAIアプリの設定に応じて外部サービスへ送信される場合があります。OFFにしても取得済みのログは取り消せません。
- 依存（`mcp`）は版を固定し、`mojicast_mcp.py.lock` で中身のハッシュも固定しています。uv は同じフォルダの .lock を自動で使います。
- 認識辞書・伏せ字・固定訳は、認識を再起動するまで効きません。MCP からは再起動しません（配信中に止まらないように）。単語エフェクトはすぐ効きます。
- 単語の登録中は「単語」の編集窓も閉じてください（開いたまま保存すると上書きされます）。
- 同梱のデザインを残したいときは、`duplicate` で複製してから調整するよう頼んでください。
